# DFPlayer 语音文件

将 `01` 文件夹完整复制到 microSD 卡根目录。DFPlayer 使用文件夹播放命令，
文件必须按以下编号保存：

| 文件 | 内容 |
| --- | --- |
| `01/001.mp3` | 前方有障碍物 |
| `01/002.mp3` | 左侧有障碍物 |
| `01/003.mp3` | 右侧有障碍物 |
| `01/004.mp3` | 前方积水 |
| `01/005.mp3` | 光线较暗，灯带开启 |
| `01/006.mp3` | 紧急求救 |
六个文件由当前固件使用，直接复制即可。若想换成自己的录音，保持相同的
目录和文件名，避免修改固件中的提示音映射。
